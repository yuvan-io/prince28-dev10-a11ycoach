# Dataset: A11yCoach

An accessibility mentor that maps UI problems to WCAG 2.2 success criteria and gives fixes from the W3C techniques and ARIA patterns.

- **Start target:** WCAG 2.2 + Understanding docs
- **Full target:** + all techniques, failures and ARIA patterns (1,500+ pages)
- **Collected by:** `scripts/fetch.py` as `examate-student-bot` (https://github.com/yuvan-io/prince28-dev10-a11ycoach): robots.txt respected, at most 4 requests at once, 0.5 s between requests to one site.

## Where the documents come from

- https://www.w3.org/TR/WCAG22/
- https://github.com/w3c/wcag
- https://github.com/w3c/aria-practices

## Terms I follow

- Every answer links to the original document.
- No personal data is collected.
